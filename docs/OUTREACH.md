# Outreach

Use these short messages for the first public conversations. Keep the ask concrete and do not imply that access, reach, money, partnership, or legal status already exists.

## Creators

EverCommons is a pre-alpha public proof for a social network that can pay creators without selling users.

The ask is small: keep your existing platforms, cross-post a few rights-clean original videos when the pilot is ready, and help test whether the creator dashboard and revenue formula make sense.

Founding creator issue:

```text
https://github.com/VoxonLabs/evercommons/issues/new?template=founding-creator.yml
```

## Engineers and Designers

EverCommons is starting with the operating rules before the platform: privacy for everyone, open core, transparent money, no provider lock-in, and capacity-gated growth.

Useful early help is finite: review the static site, improve accessibility, prototype one flow, write a threat-model checklist, or turn the MVP RFC into concrete issues.

Contributor issue:

```text
https://github.com/VoxonLabs/evercommons/issues/new?template=contributor-interest.yml
```

## Privacy and Security Reviewers

The project is intentionally pre-alpha. This is the right time to review claims, data boundaries, launch risks, and the future upload/moderation surface before public accounts exist.

Public review issue:

```text
https://github.com/VoxonLabs/evercommons/issues/new?template=privacy-security-review.yml
```

Private vulnerabilities should not be posted publicly. Follow `SECURITY.md`.

## Infrastructure Supporters

EverCommons is looking for measured pilot capacity, not blank-cheque hosting or vendor lock-in.

Good offer:

```text
5 TB S3-compatible storage and 10 TB monthly egress for a six-month, 500-user pilot under the Partner Charter.
```

Bad offer:

```text
Unlimited support in exchange for exclusivity, user data, algorithmic influence, or permanent revenue rights.
```

Infrastructure issue:

```text
https://github.com/VoxonLabs/evercommons/issues/new?template=infrastructure-sponsor.yml
```

## Healthy Digital Society Framing

Use this when explaining the larger purpose:

```text
EverCommons is a small practical attempt to make digital society healthier: people should be able to create, communicate, and contribute without being locked into surveillance economics or a single provider's rules.

The first proof is deliberately modest: public docs, a static site, open issue intake, and a capacity-gated path toward a 100-user adult pilot.
```
